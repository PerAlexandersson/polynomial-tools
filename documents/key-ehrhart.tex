If we trim the trailing zero from each $h^*$-vector and compare with the
descent polynomials of principal weak and Bruhat ideals in $S_4$, then we do
find some coincidences.

\medskip

\noindent
\textbf{Matches for the same permutation \(\sigma\).}
\begin{itemize}
\item $(1,2,3,4)$: $[1]$, agreeing with both weak and Bruhat.
\item $(1,3,4,2)$, $(1,4,2,3)$, $(2,3,1,4)$, $(3,1,2,4)$: $[1,2]$, agreeing with the weak descent polynomial.
\item $(1,4,3,2)$ and $(3,2,1,4)$: $[1,4,1]$, agreeing with both weak and Bruhat.
\end{itemize}

\noindent
\textbf{Cross-permutation coincidences.}
\begin{itemize}
\item $(2,1,4,3)$ has trimmed $h^*=[1,1]$, which equals the weak/Bruhat descent polynomial for $(1,2,4,3)$, $(1,3,2,4)$, and $(2,1,3,4)$.
\item $(2,4,1,3)$ has trimmed $h^*=[1,9,4]$, which equals the Bruhat descent polynomial for $(3,4,1,2)$.
\item $(3,1,4,2)$ has trimmed $h^*=[1,8,3]$, which equals the Bruhat descent polynomial for $(2,4,3,1)$ and $(4,2,1,3)$.
\end{itemize}

No trimmed $h^*$-vector of degree at least $4$ agrees with a weak or Bruhat
descent polynomial in $S_4$, since those descent polynomials have degree at
most $3$.
